# Security Policy

## Supported Versions

All versions of **MonerOS** are currently supported. If you find a security issue in any version, please let us know.

## Reporting a Vulnerability

We take the security of MonerOS seriously. If you discover a security vulnerability, please report it by opening an issue on our GitHub repository:

* **GitHub Issues:** [Open a Security Issue](https://github.com/MonerOS-dev/MonerOS/issues)

*(Note: Once/If our HackerOne program is officially live, we will also accept private reports there.)*

### What to Include
Please provide as much detail as possible to help us understand and resolve the issue quickly:
* A description of the vulnerability and its potential impact.
* Steps or a proof-of-concept to reproduce the issue.
* Any relevant source file paths or code snippets.

Thank you for helping keep MonerOS safe and secure!
