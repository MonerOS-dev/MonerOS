MonerOS turns any standard computer into an air-gapped hardware wallet for Monero and Bitcoin using two bootable flash drives—no expensive dedicated devices required. Exchanges fail and closed-source wallets carry supply chain and privacy risks, so MonerOS splits the workflow into HotWalletOS (for balances, unsigned transactions, and BasicSwap atomic swaps) and ColdWalletOS (a truly air-gapped vault with network drivers and package managers purged at the build level, using LUKS2 encryption and a “Sallyport” container to sign transactions safely).

Because your normal OS is bypassed and unplugged when done, it leaves no footprint behind. It’s 100% open source—you can download ready-built images on SourceForge or view and clone the source code on GitHub.
