Each of the tools you included can operate in a watch-only workflow, but the way they do it varies a lot. A good way to think about this is: what kind of public information can each chain use to track balances, and what format does each chain use for unsigned transactions? That determines how smooth your cold-signing setup will feel.

Bitcoin-family tools (Bitcoin, Litecoin, Dogecoin)
?? How watch-only works
These chains all use UTXOs, so a watch-only wallet is built by importing:

individual addresses

public keys

or an extended public key (xpub)

or descriptors (Bitcoin/Litecoin only)

Once imported, the wallet can:

track balances

detect incoming UTXOs

build unsigned transactions

?? How unsigned transactions are exported
Bitcoin Core and Litecoin Core support PSBT (Partially Signed Bitcoin Transactions).
This is the cleanest offline-signing workflow in the entire ecosystem.

Dogecoin Core does not support PSBT.
You can still build unsigned raw transactions, but signing them offline is more manual.

?? Practical workflow
Create a watch-only wallet.

Import xpub or addresses.

Build unsigned tx (walletcreatefundedpsbt for BTC/LTC, raw tx for DOGE).

Move the unsigned tx to the cold machine.

Sign offline.

Bring the signed tx back and broadcast.

Bitcoin and Litecoin are smooth; Dogecoin works but is older and clunkier.

Monero CLI
?? How watch-only works
Monero is designed for this. A watch-only wallet uses:

public spend key

private view key

This lets you:

see incoming funds

build unsigned transactions

never expose your private spend key

?? How unsigned transactions are exported
Monero produces an unsigned_tx file.
The cold machine signs it and produces a signed_tx file.

?? Practical workflow
Create watch-only wallet from view key.

Sync it (offline).

Build unsigned tx ? produces unsigned_tx.

Move file to cold machine ? sign.

Bring back signed_tx ? submit.

Monero’s workflow is one of the most secure and mature.

Avalanche CLI
Avalanche is three chains in one, so behavior varies:

?? X-Chain
Supports offline signing.

Can build unsigned transactions.

Can export for cold signing.

?? P-Chain
Supports offline signing for staking and validator operations.

?? C-Chain
Ethereum-style: unsigned transactions are JSON blobs or RLP hex.

Works similarly to ethers.

Avalanche is fully capable, but the workflow depends on which chain you’re using.

Ethers CLI (Ethereum)
?? How watch-only works
Ethereum doesn’t have “wallet files” in the same sense. A watch-only setup is simply:

an address

or an xpub (for HD wallets)

You can track balances and build unsigned transactions without any private keys.

?? How unsigned transactions are exported
Unsigned Ethereum transactions are:

JSON objects

or RLP-encoded hex strings

These can be moved to a cold machine for signing.

?? Practical workflow
Track an address or xpub.

Build unsigned tx (gas, nonce, to, value).

Export raw unsigned tx hex.

Sign offline.

Broadcast online.

It’s more manual than Bitcoin or Monero, but fully workable.
